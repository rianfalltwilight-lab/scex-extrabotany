# ExtraBotany scex.8 原仓库复核与修复

候选 `2.0-scex.8-dev`，配套兼容层 `1.4.2`；目标 Minecraft 1.21.1 / NeoForge / Java 21。生产目录未修改。

## 对照来源与保留边界

用户指定原仓库 [ExtraMeteorP/Extra-Botany](https://github.com/ExtraMeteorP/Extra-Botany)。本轮固定到：

- master：`4ad2cc9b86620801409c17366511156a3ba1b45e`，亚空之矛、空之律者、犹大、王之花园等原实现。
- 1.16：`f96f6d37c43d807e93a27d2dbe58c4c5efec8280`，薪炎、护甲和坐骑等原实现。
- 当前可维护基线为 Lounode 的 1.20.1 分支，HEAD `a4d4f2a968d559752fa3bd6e609544473109d983`，叠加已有 SCEX 改动。开工前保存了 3,542 个文件的完整快照及 Git 状态，未回退既有修改。

`audit-upstream-20260916/baseline.json` 固定提交、原始 ZIP 和前一版 JAR 的哈希。新增素材使用原始文件；数值模型按原源码的方块、UV、层级和姿态迁移。资源和模型来源记录在 `compatibility/upstream-scex8/`。当前工程的 MIT LICENSE 仍保留；原仓库这两个快照未提供根 LICENSE，不能用当前工程许可概括全部历史素材的许可。

## 构建与验证

构建命令：`gradlew.bat build validationJar --offline --console=plain`。

锁定构建：Java 21.0.12、Gradle 9.2.1、ModDev 2.0.141、NeoForge 21.1.248、Botania 456-20260822.093314-4、Curios 9.5.1+1.21.1、Patchouli 1.21.1-93。这些是可复现构建版本，不额外缩窄运行依赖范围。

- **PASS**：本体编译及资源校验；544 个模型/方块状态、1,010 个语言键、1,934 个打包资源条目，错误 0。
- **PASS**：Vicerach 隔离服 38/38 GameTest，包含全部 11 种效果的注册表身份和保存解码/移除，以及薪炎玩家状态保存回读、亚空和犹大等新增回归。实际 exit 0，正常保存并退出。
- **PASS**：同一候选 Vicerach 实体客户端 366/366 检查，包含 243 个物品模型、34 个实体、12 件旧护甲、原尺寸/方块数、实际 Shift 使用和 G 键大招；9 页渲染检查图及世界截图留存，逐页目检。实际 exit 0，正常保存并退出。
- **PASS**：配套兼容层 2/2 JUnit 合约检查；运行包 Java 类与 1.4.1 逐项一致。
- **PASS**：正式包逐项与实际受测 validation 包的运行内容一致，正式包不含 GameTest/客户端探针。
- **NOT_RUN**：完整玩家整合包、独立网络多人、第三方光影、旧损坏 NBT、跨维度/卸载重载全生命周期、长期性能和生产验收。

GameTest：`extra-items-upstream-final-gt-20260917`；客户端：`extra-items-upstream-final-client-20260917`。证据位于交付包 `evidence/runs/`。客户端图是实际 renderer 的受控角度展示，并非原 1.12/1.16 客户端与 1.21.1 的同机逐像素 A/B。

失败过程完整保留：第一轮 GameTest 两处夹具问题分别是直接 entity.tick 不增加年龄、以及按空模板包围盒查不到完整扇面；改用真实世界 tick 和按 owner 查全实体。客户端发现起跳接地时序、效果 Holder 身份问题；夹具也修正为等待真实 Shift 输入，不再依赖设置实体标志代替按键。早期失败仍记录 FAIL，不重写成 PASS。

## 交付与回滚

运行包仅包含本体 JAR 和配套兼容层；validation JAR 只用于隔离验收，正式 JAR 排除探针。兼容层 Java 类保持 1.4.1 原样，仅构建依赖改为 .8、运行范围覆盖 `[2.0-scex.7-dev,3)`。

交付清单 `manifest.json` 包含版本、大小、SHA-256、源码归档和逐项证据。源码归档复制至 `D:/Minecraft-Projects`；开工前快照及 scex.7 原交付保留。

如后续发布，由长期维护成对更新本体 .8 与兼容层 1.4.2，并在完整整包副本验证；回滚成对恢复 .7 / 1.4.1 及更新前玩家数据备份。本轮没有生产部署或公告。完整整包、网络多人、旧损坏 NBT、跨维度/卸载重载全生命周期、第三方光影和长期性能为 NOT_RUN，不能据隔离通过宣称生产验收完成。
