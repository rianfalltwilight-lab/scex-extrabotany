# ExtraBotany 1.21.1 — SCEX 2.0-scex.5-dev

This is an unofficial SCEX-maintained preview for Minecraft 1.21.1 and NeoForge 21.1.248. Porting, restoration, testing, documentation, and release preparation were primarily assisted by OpenAI Codex under maintainer supervision. Upstream authorship and the MIT license are retained in `LICENSE`, `NOTICE`, and the source archive.

## Runtime requirements

- Minecraft 1.21.1
- NeoForge 21.1.248
- Java 21
- Botania 456-20260822.093314-4
- Patchouli 1.21.1-93
- Curios 9.5.1+1.21.1
- The same ExtraBotany JAR on client and server

The separate [SCEX Botania / ExtraBotany forest-wand compatibility bridge](https://github.com/rianfalltwilight-lab/scex-botania-extrabotany-compat) is not bundled. Install bridge `1.3.0` on both client and server when the SCEX forest-wand binding behavior is required. That bridge is version-locked to this `2.0-scex.5-dev` build and covers flower→spreader, flower→pool, and pool→Manalink selection, binding, and persistence.

## Highlights

- Restores the inventoried legacy item, block, block-entity, entity, fluid, armor, relic, flower, recipe, tag, rendering, and save contracts.
- Leaves zero missing entries in the bounded registry comparison against the archived `scex.1` baseline.
- Preserves old ItemStack IDs, components, relic ownership, custom data, and tested block/entity save fields.
- Fixes the Gaia III sound lookup, enchanted-soil lifetime boundary, Trade Orchid effect lookup, legacy registrations, and multiple resource/API migration defects.
- Locks the Java, Gradle, NeoForge, Botania, Patchouli, Curios, JEI, EMI API, and KubeJS API inputs used by the validated build.

## Known limits

This is not proof of complete gameplay parity. Full multiplayer boss fights, every mount-control path, all optional-mod combinations, long-running load, forced termination, and every GPU-specific visual path remain outside the proven scope. The archived `music.ego` has no supplied audio, `flamescion_weapon` retains its original palette texture, and the butterfly projectile keeps its unfinished upstream hit behavior.

Back up worlds and test a copy before adoption. Repository publication does not itself perform or authorize a production deployment.
